ПРИМИТИВНАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ И ИСПОЛЬЗОВАНИЮ НОВОСТНОГО АГЕНТА

Что делает агент?
Он собирает новости с украинских сайтов и Telegram-каналов по ключевым словам.
Показывает их в виде таблицы и графика, сохраняет PDF и может отправить на почту или в Telegram.

1. УСТАНОВКА

1.1 Установи Python: https://www.python.org/downloads/
1.2 Распакуй ZIP-файл проекта на рабочий стол (в папку NewsAgent)
1.3 Установи библиотеки:
    - Открой командную строку (Пуск -> cmd)
    - Перейди в папку с проектом: cd Desktop\NewsAgent
    - Установи зависимости: pip install -r requirements.txt

2. ЗАПУСК ИНТЕРФЕЙСА

    streamlit run main.py

Откроется окно в браузере — там всё удобно.

3. ОТПРАВКА PDF

3.1 В Telegram:
    - Создай бота через @BotFather
    - Получи TOKEN и CHAT_ID
    - Нажми кнопку «У Telegram» в интерфейсе

3.2 В Email:
    - Введи логин, пароль и адрес получателя
    - Нажми кнопку «На Email»

4. АВТОМАТИЧЕСКАЯ РАССЫЛКА (Только Windows)

4.1 Открой Планировщик заданий
4.2 Создай задание на 08:00 для send_report.py
4.3 Создай задание на 16:00 для update_news.py

Готово! Больше ничего делать не нужно. Если что — запусти снова main.py
